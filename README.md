# 랜덤 이벤트 서바이벌

타이머를 통해 서버 내 플레이어를 선택하고 랜덤 이벤트를 제공하는 플러그인.

  <img src="https://musical-palmier-53bce7.netlify.app/.netlify/functions/random-image" width="58" align="right">

- Minecraft : 1.21.1 +
- api-version: 1.21

## 주요 기능

- 타이머가 동작하여 0초가 되면 플레이어와 이벤트를 선택하는 룰렛이 작동합니다. (기본 타이머 : 2분)
- 플레이어는 서버 내 온라인을 기준으로 하며, 서버에 플레이어가 없을 경우 타이머가 작동하지 않습니다.
- 랜덤 이벤트 목록은 아래와 같습니다.

`일반 이벤트` : 발생 확률 99%

## 관련 명령어 (OP 전용)

> 모든 명령어는 OP 권한이 필요합니다.

| 명령어                                  | 설명                                                                                    |
| --------------------------------------- | --------------------------------------------------------------------------------------- |
| `/게임시작`                             | 랜덤 이벤트 서바이벌을 시작합니다.                                                      |
| `/종료`                                 | 진행 중인 랜덤 이벤트 서바이벌을 종료합니다.                                            |
| `/이벤트 <이벤트 이름> [대상 플레이어]` | 지정한 이벤트를 즉시 발생시킵니다. 대상 플레이어를 생략하면 자신을 대상으로 지정합니다. |

### 사용 예시

게임 시작:

```
/게임시작
```

게임 종료:

```
/종료
```

이벤트 즉시 발생:

```
/이벤트 <발생시킬 이벤트 이름> [대상 플레이어]
```

```text
/이벤트 spawn_tnt Steve
/이벤트 yeet
```
